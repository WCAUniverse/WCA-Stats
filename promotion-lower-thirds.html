WELCOME

This is your promotion's own broadcast kit, the same lower thirds and sponsor pop ups WCA uses on its shows. Your roster, divisions, teams, champions and records come straight from your promotion on WCAUniverse.com.

One file does everything. Open it in Chrome and it is your control window, the one you click. Add the same file to OBS and it shows only the graphics, with a clear background.

1. PUT THE FILE SOMEWHERE SAFE

  1. Make a folder on your PC for it, for example Documents\Broadcast, and move this file into it.
  2. Inside that folder, make another folder named sponsors. Your sponsor pictures go in there.
  3. Keep the file in this folder from now on. Your settings are saved in Chrome and in OBS, and both look for the file here.

2. TURN ON THE OBS WEBSOCKET

  1. In OBS, open Tools, then WebSocket Server Settings.
  2. Tick Enable WebSocket server. Leave the port at 4455.
  3. Easiest: untick Enable Authentication. If you keep a password on, type it in SETUP here, and also open this file in Notepad and type it on the password: "" line near the top, between the quotes. That line is the only thing you ever edit by hand.
  4. Press Apply.

3. ADD IT TO OBS

  1. In the scene you want, press + under Sources and pick Browser. Name it Lower Thirds.
  2. Tick Local file and choose this file.
  3. Set Width 1920 and Height 1080. Leave Shutdown source when not visible unticked.
  4. Press OK and stretch it to cover the whole canvas. It stays invisible until you press SHOW.
  5. To use it in other scenes, right click the source, Copy, then in the other scene Paste (Reference).

Optional, the Show Rundown column: add a second Browser source, untick Local file, and paste the file's address with ?part=rundown on the end, for example file:///C:/Users/You/Documents/Broadcast/your-file.html?part=rundown. To get the address, drag the file into Chrome and copy it from the address bar.

4. OPEN THE CONTROL WINDOW

  1. Double click this file so it opens in Chrome. That window is where you work during the show.
  2. Check the top bar: OBS: connected and Roster with a number means you are ready. It reconnects by itself if OBS restarts.
  3. Press EDIT in the top bar to open or close this panel.

5. LOWER THIRDS

  1. PERSON: search your roster, pick someone, pick which division's numbers to show, then Send to Queue. Anything you type in the boxes wins over the roster.
  2. QUEUE: pick one of your shows and build the whole card in entrance order with one press. Champions come out last.
  3. During the show: READY NEXT loads the next person hidden, SHOW puts them on screen, HIDE takes them off.
  4. LOOK: shape, colors, font, size and position. Your promotion's color is at the top of the color list. Drag the graphic on the preview to move it.

6. SPONSORS AND AD READS

  1. Press SPONSORS in the top bar (or M) to switch modes.
  2. SPONSOR tab: press + New Sponsor. Give it a name, add its pictures, and write its reads. A read can be a Full 30 second one and a Quick 15 second one, or as many as you like.
  3. Pictures: put the image in your sponsors folder and pick it, or paste an image link. PNG with no background looks best.
  4. In a read, words in (brackets) show as delivery cues and [wrestler] shows as a fill in, so you know what to say live.
  5. READ tab is your script while you talk. POP-UP sets how the logo looks on stream.
  6. WCA Bets is built in. It sends your viewers to WCAUniverse.com to follow your promotion and bet on your shows for free.

7. HOTKEYS, STREAM DECK AND STREAMER.BOT

  1. SETUP, then HOTKEYS: set a key for anything. Keys work while the control window is the active window. Defaults: S show, H hide, N next, P previous, M switch mode, X hide everything.
  2. Streamer.bot or a Stream Deck with Streamer.bot can press any of these buttons without the window being active. In Streamer.bot, make an action, add the sub action OBS, Raw, pick your OBS connection and paste:
    {"requestType":"BroadcastCustomEvent","requestData":{"eventData":{"ltCmd":"show"}}}
  3. Change show to any of: show hide toggle next prev mode hideAll showLT hideLT showSP hideSP nextLogo prevLogo nextRead. The control window has to be open in Chrome for these to work.

8. KEEP A BACKUP

Everything you set up is saved in this Chrome on this PC. In SETUP, press Export JSON now and then and keep the file next to this one. If you move PCs, open the file there and Import JSON.

Get a fresh copy any time from your Graphics Studio on WCAUniverse.com. Import your JSON into the new copy and you are back where you were.

OBS WEBSOCKET

This window connects automatically every time it opens and keeps retrying. The OBS Browser Source connects on its own using the settings at the top of the HTML file — set the password there too if you use one.

HOTKEYS

Click a key, then press the key you want. Hold Ctrl, Alt or Shift with it for a combo. Esc cancels, Backspace clears. A key can only do one thing, so setting it moves it off anything else. Saved in this browser.

PREVIEW

An old TV broadcast margin, 5% in from each edge. It is only a suggestion and has nothing to do with your stream. The real edge of your video is the outer edge of the preview.
